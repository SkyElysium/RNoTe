## Usage

&emsp;&emsp; Download the static version from Realeases  
or package by yourself (Pyinstaller as example):

&emsp;&emsp;1.Execute the packaging command in the root directionary：

```
pyinstaller main.spec
```

&emsp;&emsp;2.From ```dist/main/_internal```, put ```data``` and ```lang``` into ```main```

> ```_internal``` only remains on Pyinstaller 6.0.0+
